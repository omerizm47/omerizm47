## How I work

**Evaluate before your users do.** An agent that answered correctly last week is not evidence it answers correctly today. The harness ships with the agent, not after it.

**Delete the click path.** If a deployment can be described, it can be one command. Twelve industries, one install call, nothing left to remember.

**Offline is a feature.** Both mobile apps run with no account, no network, and no telemetry. Progress lives on the device, which is where it belongs.
