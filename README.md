Scheduled regression testing for Microsoft Fabric data agents. It runs ground-truth question banks, tracks accuracy over time, fails on regressions, and produces a scorecard with diagnoses and next actions.

`Microsoft Fabric` `Python` `PowerShell` `Jupyter`

### [FabricIQ Ontology + Data Agent Jumpstart](https://github.com/omerizm47/fabric-jumpstart-fabriciq-ontology)

A one-command Fabric Jumpstart that deploys a Lakehouse, Eventhouse, Ontology, and two data agents across twelve industry templates.

`Microsoft Fabric` `Fabric CI/CD` `Python`
